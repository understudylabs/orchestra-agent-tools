What this unlocks

  • Find costly runs and distinguish model expense from executed tool expense.
  • Locate payload evidence for the model calls in those runs.
  • Build an evaluation plan around complete tasks, including failed attempts.

A join is the start of an investigation. It does not establish replay readiness, quality, savings, or complete workflow coverage.

Validate with Chargebee

  1. Export one real harness run with its tools, sub-agents and outcome.
  2. Associate each model operation with the existing x-understudy-request-id response header.
  3. Check parent spans, retries and export-window completeness.
  4. Agree on cost meaning and independently review outcome quality.
  5. Choose a workload, evaluation owner and acceptance criteria.
All amounts, identities and model names shown here are synthetic. Reports are computed by the local joiner when this overview is built. Scenario controls switch between those computed reports. No provider calls, uploads or production changes occur.
